# Haunted Sweden — Members Platform v3

**Status:** Vision / roadmap  
**Depends on:** Members v2 (SQL + billing + QR)

---

## Universe modules

| Module | Description |
|--------|-------------|
| Books | Multi-edition reading + archive unlocks |
| Investigation Archives | Deep research dossiers per place / book |
| QR Hunts | Seasonal / regional field campaigns |
| Badges | Advanced rarity, sets, prestige tracks |
| Community | Moderated UGC + research voting |
| Memberships | Premium tiers, founder lifetime |
| Webshop | Books, merch, 3D prints, downloads |
| Digital Downloads | Entitlement-gated assets |
| Newsletter | Segmented editorial + archive alerts |
| Research Database | Cross-linked claims, sources, people |

## Product principles

1. Investigation archive tone — never default social UX.
2. Content catalogs grow via data, not hard-coded book counts.
3. Public site (`/`, `/map`, `/community`) stays conversion; Members stays private.
4. Admin remains a single secure surface for operations.
5. Haunted Media Factory can feed research into member-facing archives without coupling deploy cycles.

## Non-goals

- Open social networking
- Predictable `/book1` public URLs
- Hardcoded commercial pricing in the client
